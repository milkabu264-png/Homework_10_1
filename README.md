# Проект обработки данных

## Описание

Проект содержит набор утилит для обработки структурированных данных (списков словарей). 
Включает функции для фильтрации по статусу и сортировки по дате.

## Функциональность

### 1. Фильтрация по статусу (`filter_by_state`)

Функция отбирает записи по значению ключа `state`.

**Параметры:**
- `data` (list) - список словарей с данными
- `state` (str) - значение для фильтрации (по умолчанию `'EXECUTED'`)

**Пример использования:**
```python
from src.processing import filter_by_state

data = [
    {'id': 414288290, 'state': 'EXECUTED', 'date': '2019-07-03T18:35:29.512364'},
    {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30T02:08:58.425572'},
    {'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12T21:27:25.241689'},
    {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14T08:21:33.419441'}
]

# Получить все выполненные операции
executed = filter_by_state(data)
print(executed)
# [{'id': 414288290, 'state': 'EXECUTED', 'date': '2019-07-03...'}, 
#  {'id': 939719570, 'state': 'EXECUTED', 'date': '2018-06-30...'}]

# Получить все отмененные операции
canceled = filter_by_state(data, 'CANCELED')
print(canceled)
# [{'id': 594226727, 'state': 'CANCELED', 'date': '2018-09-12...'}, 
#  {'id': 615064591, 'state': 'CANCELED', 'date': '2018-10-14...'}]
